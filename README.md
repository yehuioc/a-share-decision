# A 股决策工作台

在本机运行的 A 股研究与复盘程序：冻结当时可知的证据，分别形成机会与反证意见，交叉质疑后给出条件计划，再用后续行情和用户确认的交易复核结果。模型通过 DeepSeek 官方 API 调用，页面和 Python 研究后台独立于 Codex 运行。

本目录是唯一维护的源码目录，直接连接 [GitHub 仓库](https://github.com/yehuioc/a-share-decision)。本地使用与公开源码共用这一套实现，私人数据由 `.gitignore` 排除，发布无需再复制一套项目。

## 开始使用

需要 Windows、Python 3.12 和网络。在项目根目录的 PowerShell 中运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-background.ps1
```

首次安装运行 `setup.ps1`；已有环境只需启动后台。浏览器打开 [本地工作台](http://127.0.0.1:8765)。启动后可关闭启动窗口和 Codex；前台排错用 `run.ps1`。启动器核对服务身份与数据根目录，不接管其他占用端口的程序。

API 密钥只配置在本地 `data/model-secret.json` 的 `api_key` 字段。网页状态不返回密钥，源码仓库也不保存它。四个页面入口为「当前决策」「角色与记忆」「资料与来源」「记录与复盘」。

1. 在「资料与来源」指定行情与研究情报渠道；未指定时程序显示缺项，不擅自选择或回退供应商。默认观察工商银行 `601398`、沪深300ETF `510300`、科创芯片ETF `588290`，观察名单可调整，不表示持仓。
2. 在「当前决策」运行一轮研究。任务持久化保存，关闭页面不终止后台；失败可继续已有轮次，已完成阶段不重做。旧价格、意见和裁决不会被新判断覆盖。
3. 在「记录与复盘」确认账户起点，记录真实交易、分红、费用、资金进出和估值。模拟账本独立于实际账本，缺失项保持未知，不把成交额当作净收益。
4. 「角色与记忆」显示方法、此前意见、已发布裁决和有依据的已知结果。未发生的结果不提前写入经验。

## 情报采集与来源

当前工作流支持本地 Codex 主动采集、网页已完成情报作为补充。实际绑定唯一维护在本地 `data/settings.json` 的 `channels`：`market` 指定行情适配器，`trading.reference` 指定主来源，`additional_references` 保存用户授权的补充来源。私人对话地址留在该文件，不写进源码。

本地采集复用 `app.market.collect` 取得指定腾讯渠道的报价和未复权日线，再阅读公司、基金、交易所及相关宏观发布原文。本机已有采集任务使用 Luna/max，在工作日北京时间12:30、18:30交付，衔接13:00、19:00研究；其他安装者需自行配置采集任务。任务身份可用 `codex-automation:<任务ID>` 绑定，但不能把它作为金融事实的底层出处。

完整采集提示词唯一维护在 [prompts/intelligence-collection.md](prompts/intelligence-collection.md)，页面直接读取它。保留三个标的的价格、相关变化、近期事件、反向证据和具体缺口。采集不连接证券账户，不索要持仓、现金或费用证明。网页未更新不阻断本地交付；同一行情供应商或转载公告不能算独立交叉证据。

情报通过 `research-packet-v2` 写入 `data/packet_inbox/`，再调用既有导入入口；原始内容、来源身份、消息ID和实际接入时间一并保存。本地主包优先，晚到网页补充不能替换它。行情有独立指定渠道时，情报中的价格不能覆盖主行情。正文已接收与各标的是否能够定量研究分别展示，缺少辅助字段不统一判废；主价格无效的标的停用，其他标的继续研究。

情报采集任务需要电脑开机、Codex运行和网络可用；Python研究后台独立运行。晚到资料可用以下命令补跑最近被资料缺口阻断的时段，成功时段不重复执行，也不回填失败时间：

```powershell
.venv\Scripts\python.exe -m app.runner catch-up
```

财新本地归档是可选来源，默认暂停。只有启用后才同步，历史正文和原件仍可查看。清洗与原件目录读取本地 `data/source_status/caixin.json` 的 `root`、`raw_root`；未配置时采用项目 `data/sources/caixin`、`data/sources/caixin-raw`。同步仅只读用户已有归档，不抓取网站、不改动原件。

## 研究、计划与复盘

每轮冻结证据、方法、账户版本和已知记忆。机会研究与反证研究先独立提交，各回应一次，再由风险裁决形成当前买入、持有、减仓、卖出或不买的计划。三个角色各有独立方法与本地会话；使用同一模型不等于统计独立的预测器。共同方法见 [roles/research-principles.md](roles/research-principles.md)，接口合同见 [API.md](API.md)。

长期价值与波段时点分别评估。各角色给出1/5/20交易日方向、反证条件与有价格依据的数量及人民币得失情景；裁决事前声明触发、失效与期限。缺少账户信息只限制执行量核定，研究可注明假设继续。收益目标、风险预算和账户背景以本地配置为准，目标不构成盈利承诺。

研究当前采用零摩擦口径：手续费、佣金、税费和滑点按0进行研究测算。真实账本仍按用户确认的实际费用计算；未知费用不能当作零或宣称净盈利。聊天确认的成交可保存在 `data/research_profile.json` 的 `reported_trades`，更新后的背景放在 `current_positions`；下一轮优先使用它，旧计划保留原假设。缺少账户起点或成交日期时不虚构现金和账本。

计划结果按事前规则与精确交易日日线复核。缺历史、未知同日止盈止损顺序、T+1不能卖出或尚未到期时保留未决，不把价格上涨自动算作成交盈利。实际、模拟、未成交及失效后的假设回放分开记录。角色按各自原始判断评分，后续结果只进入其真实已知时点之后的上下文。

## 后台与模型

`install-schedule.ps1` 安装或更新 Windows研究任务，执行时间为北京时间13:00、19:00，并注册登录启动本地页面的任务。需要本机开机、网络可用和任务登录条件；安装脚本要求 Windows 时区为北京时间。原生任务、页面按钮与CLI共用研究业务和跨进程锁，同一时段不重复生成轮次。

模型公共参数唯一维护在 `app.model.MODEL`：`deepseek-flash`，开启思考、`reasoning_effort=max`、生成上限393216，单次输入与生成合计容量1048576。三角色使用独立客户端及 `data/agents/<agent_id>/sessions/` 会话，共用一个API密钥。请求设置、实际返回型号、结束原因与用量保存在本地 `data/model_calls/`，不按角色自述核验型号。超出服务端容量保留失败，不静默换模型或截断资料。

## 私人数据与源码维护

`data/` 保存账户、设置、密钥、原件、研究轮次、意见、角色记忆、任务和审计。`.venv/`、`.tmp/`、`docs/reviews/`、`private/` 及环境密钥文件也被忽略。忽略只影响 Git 收录，不删除本机文件；私人材料需另行备份，GitHub源码不能恢复它们。研究上下文会发送到所配置的DeepSeek官方API，本机账本不由模型改写。

本项目采用独立Git，外层工作区不再重复跟踪本目录；旧外层历史仍留在本机，没有上传。公开历史从已有清理后的GitHub提交延续。以后直接在本目录检查差异、提交源码并 `git push origin main`，先核对暂存文件，禁止加入私人数据。维护协作说明见 [AGENTS.md](AGENTS.md)。

开发验证在项目目录运行：

```powershell
.venv\Scripts\python.exe -m pip install --cache-dir .tmp/pip-cache -r requirements-dev.txt
.venv\Scripts\python.exe -m pytest -q --basetemp .tmp/pytest
```

测试与回放用隔离数据目录，不写正式账户。当前交易日历只核验2026年，跨年需要更新交易所休市表。服务仅监听loopback，写接口检查CSRF；不连接券商、不自动交易。模型流程或测试通过不证明投资收益。
