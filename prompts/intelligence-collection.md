# 情报收集交接

只收集用户明确指定渠道中的公开或获授权事实；不选择账户、不执行交易，不把聊天地址当作事实原始来源。

返回 `research-packet-v2`，保留 `request_id`、`message_id`、`source_reference`、`as_of`、`session`、`text` 与 `market.quotes`。时点使用带时区的 ISO 时间；`session` 为 `midday`、`close` 或 `non_trading`。

正文分别写事实、来源与发布时间、推断、相反证据、缺失信息。每个可核实事实附其原始 HTTP(S) 来源；不可核实就说明未知，不补造数字。行情写明标的、价格、观察时点与来源，历史报价不得假装当前可成交价格。

观察名单以本机附加配置为准，仅用于确定研究范围，不构成推荐。缺失渠道、报价或原文应如实保留；输出只是研究交接，不是已成交记录或收益保证。
